# LABELSystem

**Layout and Artwork Bibliographic Entry Layer** — フォトコンテスト用キャプション生成システム

Google スプレッドシートにまとめた作品情報（タイトル・ユーザ名・ユーザID・コメントなど）を、
美術館・写真展の作品キャプションを想定したテンプレートへ差し込み、
**SVG / PDF / PNG / HTML** として出力します（VRChatワールドでの展示・印刷の両方を想定）。

構成は3つだけです。

| 部品 | 役割 |
| --- | --- |
| **Google スプレッドシート** | 作品の一覧。データの置き場所はここだけです |
| **ブラウザ拡張** | X（旧Twitter）の応募投稿を読み取り、スプレッドシートへ1行として転記します |
| **LABELSystem.exe** | スプレッドシートの行を選び、テンプレートへ差し込んで出力します |

```text
[X の投稿ページ] ──ブラウザ拡張──┐
                                 ▼
                          [GAS] ⇄ [Google スプレッドシート]
                                 ▲
        [LABELSystem.exe] ───────┘──▶ テンプレートへ差し込み ──▶ SVG / PDF / PNG / HTML
```

- **インストール不要。** exe を置いて実行するだけで、専用のウィンドウが開きます。
- **サーバを立てません。** exe も拡張機能も、スプレッドシート（GAS）と直接やり取りします。このPCでポートを開くことはありません。
- スプレッドシートは普段どおり直接編集できます。LABELSystem が既存の行を書き換えることはありません。
- 絵文字や機種依存文字も、SVG / PDF / PNG で同じ見た目に出力します。

## スプレッドシートの形式

1行目を見出しとし、次の12列を使います。

| No. | テーマ | 部門 | タイトル | ユーザ名 | ユーザID | コメント | 投稿日 | 画像url(GoogleDrive) | 元投稿URL(Twitter) | 賞など | 備考 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |

- 既にこの形式でデータが入っているシートは、そのまま使えます。
- 空のシートに対して準備（`setup`）を行うと、この順番で見出しが作られます。
- 列は見出しの名前で探すため、並び替えたり、独自の列を追加したりしても動作します。

## はじめかた

### 1. exe を実行する

`LABELSystem.exe` を任意のフォルダ（例: `ドキュメント\LABELSystem`）へ置いてダブルクリックします。
LABELSystem のウィンドウが開き、同じフォルダに次のものが作られます。終了するときはウィンドウを閉じます。

```text
LABELSystem.exe
├── gas/Code.gs          スプレッドシートへ貼り付けるスクリプト
├── extension/           ブラウザ拡張
├── templates/           同梱テンプレート（A6・16:9・正方形・縦長・帯・名刺サイズ）
├── data/                接続設定（config.json）・自作テンプレート・exe内での修正（edits.json）・キャッシュ
├── output/              出力されたキャプション
└── licenses/
```

- 初回は Windows の「WindowsによってPCが保護されました」という表示が出ることがあります
  （署名のない実行ファイルのため）。「詳細情報」→「実行」で起動できます。
- ウィンドウの表示には、Windows に標準で入っている Microsoft Edge の描画機能を使います
  （普段使いのブラウザとは別枠で動き、タブや履歴には現れません）。
- ウィンドウとタスクバーには、exe と同じアイコンが表示されます。

### 2. スプレッドシートへ接続する（初回のみ）

ウィンドウに表示される手順に従います。詳細は [docs/gas.md](docs/gas.md) にあります。

1. スプレッドシートの「拡張機能」→「Apps Script」へ `gas/Code.gs` を貼り付ける
2. 関数 `setup` を実行して **トークン** を控える
3. ウェブアプリとしてデプロイして **URL** を控える
4. LABELSystem のウィンドウへURLとトークンを入力する

### 3. ブラウザ拡張を読み込む（Xから取り込む場合）

- **Chrome / Edge**: `chrome://extensions` →「デベロッパー モード」を有効化 →
  「パッケージ化されていない拡張機能を読み込む」→ exe と同じフォルダの `extension` を選択
- **Firefox**: `about:debugging#/runtime/this-firefox` →「一時的なアドオンを読み込む」→ `extension/manifest.json`

拡張機能のボタンを押し、「接続設定」へ **手順2と同じURLとトークン** を入力します。

## 使い方

### Xの投稿をスプレッドシートへ転記する（ブラウザ拡張）

1. Xで応募投稿の**詳細ページ**を開き、拡張機能のボタンを押す。
2. 読み取った内容（ユーザ名・ユーザID・コメント・投稿日・元投稿URL）を確認し、テーマ・部門・タイトルを入力・修正する。
   - タイトルは、本文に「タイトル：○○」と明記されている場合のみ自動で入ります。
   - コメントは、本文からタイトル行・ハッシュタグ・URLを除いたものです。
   - テーマと部門は、前回入力した値が最初から入ります。
3. 「スプレッドシートへ登録」を押す。シートの末尾に1行追加され、No. が続きの番号で振られます。

同じ投稿（元投稿URLが同じ）は二重に登録されません。
「画像url(GoogleDrive)」「賞など」「備考」は空欄で追加されるので、スプレッドシート上で入力してください。
LABELSystem.exe を起動していなくても転記できます。

### キャプションを出力する（LABELSystem.exe）

1. 左の一覧には、スプレッドシートのすべての列が表示されます（横にスクロールできます）。行をクリックすると、右にプレビューが表示されます。
2. テンプレートを選びます。
3. 出力したい行にチェックを入れ、出力形式を選んで「出力」を押します。`output/` フォルダへ保存されます。

行は次の方法でまとめて選べます。

- **範囲を選択**: 一覧の上の欄に No. の開始と終了を入れて「範囲を選択」（例: 10 〜 25）
- **Shift + クリック**: 1つ目の行にチェックを入れ、Shift を押しながら別の行のチェックを押すと、その間がすべて選択されます
- 見出しのチェックボックスで、表示中の行すべてを選択・解除できます（絞り込みと組み合わせられます）

- スプレッドシートを編集したあとは「再読み込み」を押します。
- キャプション用に少しだけ直したい場合は、行を選んで「この行の内容を修正」を押します（下記）。
- プレビューに黄色の警告が出た場合は、スプレッドシート側の文章を直してください。
  - **表示領域に収まりません** … コメントやタイトルを短くする
  - **どのフォントでも表示できない文字があります** … その文字を取り除く
  - **フォントを利用できません** … 指定フォントをインストールする
- 青色の通知は対応不要です（文字サイズを許容範囲内で縮小した／絵文字などを別フォントの字形で表示した）。

### exe の中だけで内容を修正する

スプレッドシートは変えずに、キャプションに載せる内容だけを直したいとき（長すぎるコメントを縮める、表記を整えるなど）に使います。

1. 行をクリックし、プレビューの下の「この行の内容を修正」を押す。
2. テーマ・部門・タイトル・ユーザ名・ユーザID・コメント・投稿日・賞など・備考を書き換える。入力に合わせてプレビューが更新されます。
3. 「修正を保存」を押す。

- 修正はこのPCの `data/edits.json` に保存され、**スプレッドシートには書き込まれません**。プレビューと出力には修正後の内容が使われます。
- 修正した項目は、一覧で色が付きます。カーソルを合わせると、スプレッドシート上の元の値が表示されます。
- 「スプレッドシートの内容に戻す」で、その行の修正をすべて取り消せます。
- 修正は No. で行に結び付けています。スプレッドシート側で No. を振り直すと、別の行に修正が付いてしまうので注意してください。
- 修正した項目は、スプレッドシート側の値を後から変えても、修正した内容が優先されます。

| 形式 | 用途 |
| --- | --- |
| SVG | マスター出力。PDF・PNGはこのSVGから生成します |
| PDF | 印刷用。実寸・フォント埋め込み。全件を1ファイルにまとめた `captions-all.pdf` も生成可能 |
| PNG | 共有・VRChatワールドのテクスチャ用（既定300dpi。`data/config.json` の `pngDpi` で変更） |
| HTML | CSSを内包した単一ファイル。文字がテキストとして残ります。`captions-all.html` も生成可能 |

ファイル名は `{No.}_{ユーザID}_{タイトル}.{拡張子}` です（例: `42_example_星降る夜.pdf`）。

### フォントの埋め込み

出力時に「フォントを埋め込む」にチェックを入れると、そのフォントが入っていないPCや環境でも同じ見た目になります。

| 形式 | 埋め込みの方法 |
| --- | --- |
| PDF | 常に埋め込みます（使った文字だけ） |
| PNG | 画像なので、フォントは不要です |
| SVG | 文字を図形（アウトライン）に変換します。文字としての選択・検索はできなくなります |
| HTML | フォントファイルを内包します。1ファイルあたり数MB〜十数MB大きくなります |

フォントを埋め込んだファイルを配布・公開する場合は、そのフォントのライセンスが埋め込みや再配布を認めているか確認してください。

## テンプレート

最初から次のテンプレートが入っています。

| テンプレート | 大きさ | 用途 |
| --- | --- | --- |
| Example (A6 横) | 148 × 105 mm | 印刷用のキャプション |
| 16:9 横長（濃色 / 淡色） | 1920 × 1080 px | 画面・VRChatワールドの展示パネル |
| 正方形 | 1080 × 1080 px | SNSの投稿画像など |
| 9:16 縦長 | 1080 × 1920 px | 縦長の画面・パネル |
| 帯・名札 | 1920 × 480 px | 作品の下に置く横長の名札（タイトル・ユーザ名・ユーザID） |
| 名刺サイズ | 91 × 55 mm | 印刷用の小さなキャプション |

px で大きさを指定しているテンプレートは、PNG がその画素数ちょうどで出力されます。
ロゴやイベント名を入れたい場合は、「複製して新規作成」で複製し、ブロックエディタで画像や文字を足してください。

テンプレートは、ウィンドウ右上の3つのボタンで扱います。書式は [docs/template-format.md](docs/template-format.md) を参照してください。

| ボタン | 動作 |
| --- | --- |
| 編集・コードを確認 | 選択中のテンプレートを、ブロックエディタまたはコードで編集します |
| 複製して新規作成 | 選択中のテンプレートを元に、新しいテンプレートを作ります |
| インポート | 受け取った `template.json` と `template.svg`（任意で `.html` / `.css`）を選んで取り込みます |

編集画面には2通りの編集方法があり、タブで切り替えられます。どちらも同じファイルを編集するので、行き来できます。

- **ブロック**: 項目（スプレッドシートの列）・固定の文字・線・四角・画像を追加し、右のプレビュー上でドラッグして配置します。
  文字サイズ・最大行数・折り返す幅・色・揃え・フォントなどはフォームで設定します。
  - **揃え**: 左右（左・中央・右）に加えて、枠（最大行数ぶんの高さ）の中での上下（上・上下中央・下）を選べます。
    行数が少ない作品でも、文字が枠の中央や下端に来るようにできます。
  - **元に戻す / やり直す**: Ctrl+Z / Ctrl+Shift+Z（Ctrl+Y でも可）。ボタンでも操作できます。
  - **スナップ**: ドラッグ中、ほかのブロックの端・中央、用紙の端・中央、文字の下端に吸着し、ガイド線が表示されます。
    Alt を押している間は吸着しません。チェックボックスで常に無効にもできます。
  - **直線移動**: Shift を押しながらドラッグすると、水平または垂直にだけ動きます。
  - **大きさの変更**: 選択中のブロックに出るつまみで、四角の大きさ・項目の折り返す幅・線の端点を変えられます
    （Shift で、四角は縦横比を保ち、線は水平・垂直・45度に固定）。
  - **キー操作**: 矢印キーで1ずつ移動（Shift で10）、Delete で削除、Ctrl+D で複製、Esc で選択解除。
  - **用紙に揃える**: 左・中央・右／上・中・下のボタンで、用紙に対して揃えられます。
  - **用紙サイズ**: 単位を mm（印刷向け）と px（画像・画面向け）から選べます。単位を切り替えても配置は保たれます。
    px で指定したテンプレートは、PNG がその画素数ちょうどで出力されます（例: 1920 × 1080）。
  - **フォント**: このPCに入っているフォントの一覧から選べます。項目ごとに別のフォントも指定できます。
  - **背景**: 「用紙の設定」で背景色を選べます。「透明（背景なし）」にすると、PNG は背景が透明になります。
  - **画像**: 「＋ 画像」でロゴなどの画像（PNG / JPEG / SVG、8MBまで）を挿入できます。画像はテンプレートの中に埋め込まれるので、
    元の画像ファイルを消したり、テンプレートを別のPCへ渡したりしても表示されます。大きさは縦横比を保って変えられます（Shift で自由変形）。
  ブロックの配置は、HTML出力にも自動で反映されます（`template.html` / `template.css` を自動で作り直します）。
  HTMLだけ別のデザインにしたい場合は、`template.html` / `template.css` をコードのタブで直接編集してください。
  直接編集した時点で連動は止まり、「ブロック」タブのチェックボックスで再び連動させられます。
- **コード**: `template.json` / `template.svg` / `template.html` / `template.css` を直接編集します。

入力するたびに右側のプレビューが更新されます（保存前でも反映されます）。プレビューは3種類を切り替えられます。

- **SVG / PDF / PNG の見た目**
- **HTML の見た目**
- **HTML の出力コード** … HTML出力で実際に書き出されるコード一式（CSSを含む1ファイル）

保存したテンプレートは `data/templates/<id>/` に置かれます。同梱の `example` を編集して保存した場合も、
元のファイルは変更せず `data/templates/example/` に保存し、そちらを優先して使います。
`data/templates/` へフォルダを直接コピーして追加することもできます。

テンプレートで使える変数:

| 変数 | 列 | 変数 | 列 |
| --- | --- | --- | --- |
| `{{no}}` | No. | `{{userid}}` | ユーザID |
| `{{theme}}` | テーマ | `{{comment}}` | コメント |
| `{{category}}` | 部門 | `{{date}}` | 投稿日 |
| `{{title}}` | タイトル | `{{award}}` | 賞など |
| `{{username}}` | ユーザ名 | `{{note}}` | 備考 |

## フォント

テンプレートが指定するフォントは、利用者自身がPCへインストールしてください（フォントファイルは同梱していません）。
インストールせずに使う場合は `data/fonts/` にフォントファイルを置きます。
サンプルテンプレートは [Noto Sans JP](https://fonts.google.com/noto/specimen/Noto+Sans+JP) を使用します。
指定フォントが無い場合は代替フォントで描画し、プレビューに警告を表示します。

> 可変フォント（Variable Font）版は既定ウェイトしか使えません。
> ウェイト別の静的フォント（`NotoSansJP-Regular.ttf` など）を導入してください。

絵文字・機種依存文字・他言語の文字など、テンプレートのフォントに無い文字は、PCにある別のフォントから字形を探し、
輪郭（ベクター図形）としてSVGへ埋め込みます。そのため SVG / PDF / PNG のどれでも同じ見た目になります。

- 絵文字は Windows の「Segoe UI Emoji」（または「Noto Emoji」）の字形を使います。カラー絵文字・結合絵文字に対応します。
- 国旗は Windows のフォントに収録されていないため、「JP」のような文字になります。
- 絵文字の見た目はXの表示とは異なります。HTML出力では、閲覧するブラウザ・OSの絵文字で表示されます。

## 知っておいてほしいこと

- **インターネット接続が必要です**（データがスプレッドシートにあるため）。通信には1回あたり数秒かかることがあります。
- `data/config.json` と拡張機能の設定には、スプレッドシートへ接続するためのURLとトークンが入っています。
  **他の人へ渡したり公開したりしないでください。** 漏れた可能性がある場合は、Apps Script で `setup` を再実行するとトークンが新しくなります。
- バックアップは、スプレッドシートの「変更履歴」「コピーを作成」を使ってください。
- 拡張機能からの登録は投稿の**詳細ページ**でのみ行えます（タイムライン上での誤取得を防ぐため）。
- 拡張機能が読み取るのは、ページに表示されている表示名・ユーザーID・本文・投稿日・URLだけです。
  Cookieやログイン情報には触れず、X API も使いません。
- Xのページ構造が変わって「投稿情報を取得できませんでした」と表示されるようになった場合は、
  [extension/src/xPostExtractor.ts](extension/src/xPostExtractor.ts) 先頭の `X_SELECTORS` を修正します。
  それまでの間は、拡張機能の「手動入力」か、スプレッドシートへの直接入力で続けられます。
- HTML出力はブラウザが改行位置を決めるため、SVG / PDF / PNG と改行位置が一致しないことがあります。
- 配布している exe は Windows 10 / 11（64bit）用です。

## 開発者向け

Node.js 22 以上が必要です。

```sh
git clone https://github.com/ChikumaTateshina/LABELSystem.git
cd LABELSystem
npm install
npm start            # ソースから起動（ウィンドウが開く）
npm test             # 自動テスト（Googleへは接続しません）
npm run lint
npm run typecheck
npm run build        # ブラウザ拡張 → extension/dist
npm run build:exe    # 単一実行ファイル → dist/LABELSystem.exe
```

```text
src/
├── main.ts / exeMain.ts   入口（ソースから起動 / exe）
├── start.ts               起動処理
├── window.ts              ウィンドウの表示と、画面との直接通信（サーバなし）
├── app.ts                 画面から呼ばれる処理（行を読む・プレビュー・出力）
├── sheet.ts               スプレッドシート（GAS）の読み取りと追記。拡張機能と共用
├── parser.ts              投稿本文の解析（拡張機能で使用）
├── template.ts            テンプレートの読み込み・変数置換
├── render/                自動改行・フォント・SVG / PDF / PNG / HTML 生成
└── ui/                    画面（HTML / CSS / JavaScript）
extension/                 ブラウザ拡張（X の投稿 → スプレッドシート）
gas/Code.gs                スプレッドシート側のスクリプト（読む・末尾へ追記する）
templates/                 同梱テンプレート
tests/                     テスト（Code.gs はスプレッドシートを模したモック上で実行）
```

- 画面と本体は、ウィンドウとの間のパイプ（Chrome DevTools Protocol）で直接やり取りします。HTTPサーバもポートも使いません。
- exe は Node.js の Single Executable Application 機能で作ります。ネイティブモジュールは使っていません。
- タグ（`v2.0.0` など）をpushすると、GitHub Actions が exe と拡張機能をビルドして Release へ添付します。
- [docs/LABELSystem.md](docs/LABELSystem.md) は当初の要件・仕様書です。現在の実装は、そこからローカルDB・ローカルサーバ・
  イベント管理・バックアップ等を省き、スプレッドシートを中心にした最小構成へ改めています。

ブロックエディタの「外部ファイル・URLの参照」に、テンプレートや埋め込みSVGのhref/src、CSSのurl()/@importで参照されるファイル・URLを表示します。参照先を自動取得・内包する機能ではありません。
