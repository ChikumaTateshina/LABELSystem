# スプレッドシート（GAS）の準備

LABELSystem.exe とブラウザ拡張は、スプレッドシートに設置した Google Apps Script（GAS）を通して、
作品の一覧を「読む」「末尾へ1行追記する」ことだけを行います。

- 既存の行を書き換えること、列を追加すること、行を削除することはありません。
- 既にデータが入っているスプレッドシートを、そのまま使えます。

この作業は最初に一度だけ行います。所要時間は5〜10分です。

## 1. シートを確認する

対象は、スプレッドシートの**いちばん左のシート**です
（別のシートを使う場合は、`Code.gs` 先頭の `SHEET_NAME` にシート名を書きます）。

1行目が次の見出しになっていることを確認します。

```text
No. | テーマ | 部門 | タイトル | ユーザ名 | ユーザID | コメント | 投稿日 | 画像url(GoogleDrive) | 元投稿URL(Twitter) | 賞など | 備考
```

- 列は見出しの名前で探します。並び順が違っても、独自の列が増えていても構いません。
  全角・半角、空白、大文字・小文字の違いは無視します。
- 新しく作る場合は、空のスプレッドシートを用意するだけで構いません。手順3で見出しが自動で作られます。

## 2. スクリプトを貼り付ける

1. スプレッドシートのメニュー「拡張機能」→「Apps Script」を開く。
2. エディタに最初から入っている内容をすべて消す。
3. `gas/Code.gs`（LABELSystem.exe と同じフォルダにあります）の内容をすべて貼り付けて保存する。

## 3. setup を実行する

1. エディタ上部の関数の選択欄で `setup` を選び、「実行」を押す。
2. 初回は権限の確認が表示される。「権限を確認」→ 自分のアカウントを選ぶ →
   「詳細」→「（プロジェクト名）に移動」→「許可」。
3. 画面下の「実行ログ」に表示される **トークン**（64文字の英数字）を控える。

「列『○○』が見つかりません」と表示された場合は、1行目の見出しを手順1のとおりに直してから、もう一度実行します。

## 4. ウェブアプリとしてデプロイする

1. 右上の「デプロイ」→「新しいデプロイ」。
2. 「種類の選択」の歯車 →「ウェブアプリ」。
3. 次のように設定して「デプロイ」。
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
4. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）を控える。

> 「全員」にしても、トークンを知らなければデータの読み書きはできません。
> URLとトークンはスプレッドシートへのアクセス手段です。公開の場所へ書かないでください。

## 5. URLとトークンを入力する

同じ2つを、次の両方へ入力します。

- **LABELSystem.exe** … ウィンドウの「初期設定」（設定済みの場合は右上の「接続設定」）
- **ブラウザ拡張** … 拡張機能のボタンを押して開く画面の「接続設定」

どちらも、入力時に接続を確認してから保存します。

## 追記される内容

ブラウザ拡張で登録すると、シートの末尾に1行追加されます。

| 列 | 入る値 |
| --- | --- |
| No. | 既存の最大の番号 + 1。書式は既存の行に合わせます（`12`→`13`、`007`→`008`、`A-041`→`A-042`） |
| テーマ / 部門 / タイトル | 登録確認画面で入力した値 |
| ユーザ名 / ユーザID / コメント / 投稿日 / 元投稿URL(Twitter) | Xの投稿から読み取り、確認画面で修正した値 |
| 画像url(GoogleDrive) / 賞など / 備考 | 空欄（スプレッドシート上で入力します） |
| 見出しが上記以外の列 | 空欄 |

- 同じ投稿（元投稿URLの投稿IDが同じ）が既にある場合は追加しません。`x.com` と `twitter.com` の違いは無視します。
- 「=」や「+」で始まる文章は、数式として実行されないよう文字として保存します。

## トークンを変更する（漏れた可能性がある場合）

1. Apps Script で `setup` をもう一度実行する（シートのデータは変わりません。トークンだけが新しくなります）。
2. LABELSystem.exe とブラウザ拡張の「接続設定」に、新しいトークンを入力する。

## スクリプトを更新する（LABELSystem を更新したとき）

「スプレッドシート側のスクリプトが古い形式です」と表示された場合:

1. Apps Script のエディタへ新しい `gas/Code.gs` を貼り付けて保存する。
2. 「デプロイ」→「デプロイを管理」→ 鉛筆のアイコン → バージョン「**新バージョン**」→「デプロイ」。
   （「新しいデプロイ」を作るとURLが変わってしまいます。必ず既存のデプロイを編集してください）

## トラブル時

| 表示 | 原因と対処 |
| --- | --- |
| トークンが一致しません | 入力したトークンが違う。`setup` をやり直した場合は新しいトークンを入力する |
| 想定外の応答が返されました | アクセスできるユーザーが「全員」になっていない、またはURLが `/exec` で終わっていない |
| スプレッドシートへ接続できません | インターネット接続、またはURLの誤り |
| 列「○○」が見つかりません | 1行目の見出しが変更されている。手順1の見出しへ戻す |
| 他の操作が実行中です | 別の人の登録と重なった。少し待ってやり直す |
| setup を実行してください | 手順3を行っていない |

## 引継ぎ時の注意

ウェブアプリは、**デプロイした人のGoogleアカウントの権限**で動いています。
その人のアカウントが使えなくなると、ウェブアプリも動かなくなります。
担当者が交代するときは、後任がスプレッドシートを開ける状態にしたうえで、後任のアカウントで
手順3〜5（`setup` の実行・新しいデプロイ・URLとトークンの入力）をやり直してください。
団体の共有アカウントでスプレッドシートを所有しておくと、この作業を省けます。
