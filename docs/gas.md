# Google スプレッドシート連携（GAS）

スプレッドシートに書かれた作品情報を、CSVの書き出し・読み込みをせずに取り込むための連携です。

```text
Google スプレッドシート ──(GAS ウェブアプリ / JSON)──▶ LABELSystem サーバ ──▶ DB
                                 ▲ 「シートから同期」ボタン、または一定間隔で自動取得
```

- **方向はシート → LABELSystem の一方向**です。LABELSystem からシートへは書き込みません
  （例外: GAS自身が、行を識別するための `id` 列をシートへ追記します）。
- **新しい行だけ**を取り込みます。取り込み済みの行をシートで書き換えても、DB側は変わりません。
  取り込み後の修正は管理画面で行ってください。
- 同じX投稿（`source_post_url` が同じ）は、拡張機能から登録済みであれば取り込まれません。

## 1. シートを用意する

シート名を `entries` にし、1行目を列名にします。列の順番は自由で、不要な列は無視されます。

| title | user_display_name | user_id | comment | source_post_url |
| --- | --- | --- | --- | --- |
| 星降る夜 | Example User | @example | 静かな夜の海を撮影しました。 | https://x.com/example/status/… |

使える列名（どれか1つ）:

| 内容 | 列名 |
| --- | --- |
| タイトル | `title` / タイトル / 作品タイトル / 作品名 |
| ユーザ名 | `user_display_name` / `username` / ユーザ名 / ユーザー名 / 表示名 / 名前 |
| ユーザID | `user_id` / `userid` / ユーザID / ユーザーID / アカウント |
| コメント | `comment` / コメント |
| 元投稿URL（任意） | `source_post_url` / `url` / 元投稿URL / 投稿URL / 応募URL |
| 管理番号（任意） | `entry_number` / `no` / 番号 / 管理番号 |

Googleフォームの回答シートをそのまま使う場合は、質問のタイトルを上の列名に合わせてください。

## 2. スクリプトを設置する

1. スプレッドシートのメニュー「拡張機能」→「Apps Script」を開く。
2. エディタの内容を [integrations/gas/Code.gs](../integrations/gas/Code.gs) の内容で置き換えて保存する。
   シート名が `entries` でない場合は、先頭の `SHEET_NAME` を変更する。
3. 関数 `setupToken` を選んで「実行」する（初回は権限の承認が必要）。
   実行ログに表示された**トークン**を控える。
4. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
5. 表示された**ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）を控える。

> 「全員」にしても、トークンを知らなければ内容は取得できません。
> URLとトークンは応募者の情報へのアクセス手段です。公開の場所へ書かないでください。

## 3. LABELSystem 側を設定する

`data/config.json` に追記し、サーバを再起動します。

```json
"sheet": {
  "url": "https://script.google.com/macros/s/…/exec",
  "token": "（setupToken で表示されたトークン）",
  "autoSyncMinutes": 0
}
```

- 管理画面の一覧に「**シートから同期**」ボタンが現れます。押すと新しい行が取り込まれます。
- `autoSyncMinutes` を `5` などにすると、サーバ起動中はその間隔で自動的に取り込みます（`0` で無効）。

`data/config.json` はGit管理対象外です。URLとトークンをリポジトリへ入れないでください。

## GASを使わない方法（CSVとして公開）

応募者の情報を含まない、公開してよいシートであれば、
「ファイル」→「共有」→「ウェブに公開」→ 形式「カンマ区切り形式（.csv）」のURLを `sheet.url` に指定するだけでも同期できます
（`token` は不要）。この場合、行の識別には `id` 列、無ければ「タイトル・ユーザ名・ユーザID」を使うため、
これらを後から書き換えると別の作品として取り込まれます。**URLを知っていれば誰でも読める**点に注意してください。

## トラブル時

| 表示 | 原因と対処 |
| --- | --- |
| `unauthorized` | トークンが一致しない。`setupToken` をやり直した場合は `sheet.token` も更新する |
| シートからHTMLが返されました | ウェブアプリのアクセス権が「全員」になっていない、またはURLが `/exec` でない |
| スプレッドシートを取得できませんでした | ネットワーク、またはURLの誤り |
| 取り込めなかった行がある | 管理番号の重複など。表示された理由を確認する |

スクリプトを書き換えた後は、「デプロイ」→「デプロイを管理」→ 編集 → バージョン「新バージョン」で再デプロイしてください。

連携が使えない場合でも、シートをCSVで保存して「インポート」すれば運用を続けられます。
