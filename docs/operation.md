# 運用手順

## 毎回の準備

1. `npm start` でサーバを起動する（終了は Ctrl+C）。
2. <http://127.0.0.1:38471/> で管理画面を開く。
3. 画面右上の「イベント」が今回のコンテストになっていることを確認する。

## 応募作品を登録する

### Xから登録する（通常）

1. Xで応募投稿の**詳細ページ**を開く。
2. ブラウザの拡張機能ボタン「キャプションへ登録」を押す。
3. 登録確認画面で内容を確認・修正する。
   - タイトルは、本文に「タイトル：○○」と明記されている場合のみ自動で入ります。空欄なら入力してください。
   - コメントは投稿本文からタイトル行・ハッシュタグ・URLを除いたものです。
4. 「登録」を押す。管理番号が自動で振られます。

同じ投稿を再度登録しようとすると「この投稿は既に登録されています」と表示され、登録済みの作品を開けます。

### 手動で登録する

- 拡張機能で取得に失敗した場合: ポップアップの「手動入力」
- Xを介さない場合: 管理画面の「＋ 手動登録」

### まとめて登録する（スプレッドシートから）

1. スプレッドシートの1行目を列名にする。

   ```csv
   entry_number,title,user_display_name,user_id,comment,source_post_url
   001,星降る夜,Example User,@example,静かな夜の海を撮影しました。,https://x.com/...
   ```

   `entry_number` と `source_post_url` は省略できます。「タイトル」「ユーザー名」「コメント」など日本語の列名も使えます。
2. CSV（UTF-8）として保存する。
3. 管理画面の「インポート」でファイルを選ぶ。

登録済みの投稿や、使用済みの管理番号の行はスキップされ、理由が表示されます。

### スプレッドシートから自動で取り込む（GAS連携）

[gas.md](gas.md) の設定をしておくと、一覧の「シートから同期」ボタン、または一定間隔の自動同期で、
シートに追加された行が取り込まれます。取り込み済みの行は変更されません。

## 内容を確認・修正する

一覧から作品を選ぶと編集画面が開き、右側にプレビューが表示されます。

- 黄色の警告が出たら対応が必要です。
  - **表示領域に収まりません** … コメントやタイトルを短くする
  - **どのフォントでも表示できない文字があります** … その文字（国旗の絵文字など）を取り除く
  - **フォントを利用できません** … 指定フォントをインストールする
- 青色の通知は対応不要です（文字サイズを許容範囲内で縮小した／絵文字などを別フォントの字形で表示した）。
- 確認が済んだらステータスを **Confirmed** にして保存します。
- 元投稿の本文・URLは別に保持され、編集しても変わりません。

## キャプションを出力する

- **1件ずつ**: 編集画面の「SVG出力」「PDF出力」「PNG出力」「HTML出力」
- **まとめて**: 一覧で作品を選択（選択しなければ全件）→「一括出力」→ 形式を選んで「出力する」
  - 出力先は `output/`。ファイル名は `{管理番号}_{ユーザID}_{タイトル}.{拡張子}`
  - 「1ファイルにまとめた…」を選ぶと `captions-all.pdf` / `captions-all.html` も作成
  - Confirmed の作品は出力後に **Exported** になります

用途の目安: 印刷はPDF、VRChatワールドのテクスチャや共有はPNG、Web掲載や文字の再利用はHTML。

## バックアップ

- 管理画面の「バックアップ」: `data/backups/<日時>/` に `database.sqlite` と `entries.json` を保存
- 受付期間中は毎日、出力前後にも実行することを推奨します。
- さらに `data/` ディレクトリ全体を、定期的に別の場所（外付けドライブ等）へコピーしてください。

### 復旧

1. サーバを停止する。
2. `data/database.sqlite` を、バックアップの `database.sqlite` で置き換える
   （`database.sqlite-wal` / `database.sqlite-shm` があれば削除する）。
3. `npm start` で起動する。

DBが壊れて開けない場合は、新しい `data/` で起動し、バックアップの `entries.json` を「インポート」します。

## トラブル時

| 症状 | 対処 |
| --- | --- |
| 拡張機能が「接続できません」 | サーバが起動しているか、拡張機能の「設定」のURLが正しいか確認 |
| 拡張機能が「取得できませんでした」 | 「手動入力」で続行。繰り返す場合は [x-extractor.md](x-extractor.md) |
| `Database migration required.` | バックアップ後に `npm run migrate` |
| 文字が豆腐（□）になる | PC内のどのフォントにも無い文字。文章から取り除く |
| 「シートから同期」が失敗する | [gas.md](gas.md) の「トラブル時」を確認。CSVで保存して「インポート」でも可 |
| ポートが使用中 | `data/config.json` の `server.port` を変更（拡張機能の設定も変更） |
