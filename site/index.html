応募投稿から、
展示用キャプションまで。

LABELSystem は、フォトコンテストの応募投稿を Google スプレッドシートにまとめ、 作品キャプションをテンプレートから一括で出力するシステムです。 VRChat ワールドでの展示にも、印刷にも使えます。

ダウンロード（Windows） 導入方法を見る

無料・オープンソース（MIT License）／ Windows 10・11（64bit）／ インストール不要

しくみ

部品は3つだけ。データの置き場所はスプレッドシート1つで、専用のサーバやデータベースは要りません。

取り込む

ブラウザ拡張

X（旧Twitter）の応募投稿を開いてボタンを押すと、ユーザ名・ユーザID・コメント・投稿日・URL を読み取り、スプレッドシートへ1行として転記します。

まとめる

Google スプレッドシート

作品の一覧です。賞や備考の記入、表記の修正は、いつもどおりスプレッドシート上で行えます。運営メンバーとの共有もそのまま。

→
出力する

LABELSystem.exe

スプレッドシートの行を選び、テンプレートへ差し込んで出力します。プレビューで仕上がりを確認しながら、まとめて書き出せます。

  • PNG　ワールドのテクスチャ・画像共有に
  • PDF　実寸・フォント埋め込みで印刷に
  • SVG　拡大しても劣化しないマスター
  • HTML　文字がテキストとして残る1ファイル

できること

手作業でのコピー＆ペーストと、1枚ずつのレイアウト調整をなくします。

応募投稿をワンクリックで転記

投稿の詳細ページから必要な項目を読み取ります。本文に「タイトル：○○」とあれば、タイトルも自動で入ります。同じ投稿の二重登録は防ぎます。

まとめて選んで、まとめて出力

No. の範囲指定や Shift＋クリックで行を一括選択。全件を1つの PDF / HTML にまとめることもできます。

長い文章も自動で収める

枠に合わせて自動で改行し、収まらなければ許容範囲内で文字を小さくします。それでも収まらない作品は、警告で知らせます。

絵文字・機種依存文字に対応

テンプレートのフォントに無い文字は、別のフォントから字形を探して描きます。PNG・PDF・SVG のどれでも同じ見た目になります。

テンプレートを画面上で作れる

ブロックエディタで、項目・文字・線・四角・画像（ロゴなど）をドラッグして配置。スナップ、元に戻す、用紙サイズ（mm / px）、背景色にも対応します。

スプレッドシートを書き換えない

アプリが既存の行を変更することはありません。キャプション用に少しだけ直したい場合は、アプリの中だけで修正できます。

画面

起動すると専用のウィンドウが開きます。画面内のデータは説明用の架空のものです。

出力例

最初から入っている7種類のテンプレートで出力したものです。複製して、ロゴやイベント名を足して使えます。

導入方法

必要なのは、Windows の PC と Google アカウントだけです。準備が要るのは初回だけです。

  1. exe をダウンロードして実行する

    Releases から LABELSystem.exe をダウンロードし、好きなフォルダ（例: ドキュメント\LABELSystem）に置いてダブルクリックします。同じフォルダに、テンプレートやブラウザ拡張など必要なものが作られます。

  2. スプレッドシートを用意する

    Google スプレッドシートを開き、「拡張機能」→「Apps Script」に、exe と同じフォルダにできた gas/Code.gs を貼り付けます。関数 setup を実行するとトークンが発行され、空のシートには見出しが作られます。続けてウェブアプリとしてデプロイし、URL を控えます。

  3. アプリにつなぐ

    LABELSystem のウィンドウに、手順2の URL とトークンを入力します。接続できると、スプレッドシートの行が一覧に表示されます。

  4. ブラウザ拡張を読み込む（X から取り込む場合）

    Chrome / Edge の拡張機能の画面で「デベロッパー モード」を有効にし、「パッケージ化されていない拡張機能を読み込む」から、exe と同じフォルダの extension を選びます。拡張機能にも同じ URL とトークンを入力します。

初回の起動時に「Windows によって PC が保護されました」と表示されることがあります（署名のない実行ファイルのため）。「詳細情報」→「実行」で起動できます。
詳しい手順は README と スプレッドシート連携の説明 にあります。

ユースケース

同じスプレッドシートから、用途に合わせた形で何度でも出力できます。

VRChat ワールドでの作品展示

応募作品の隣に置くキャプションを、全作品ぶんまとめて PNG で出力。px 指定のテンプレートなら、その画素数ちょうどで書き出されるので、テクスチャとしてそのまま使えます。背景を透明にもできます。

使うもの: 16:9 横長 ／ 9:16 縦長 ／ 帯・名札 ＋ PNG

会場での印刷展示

実寸・フォント埋め込みの PDF を出力し、全作品を1ファイルにまとめて印刷へ。美術館や写真展の作品キャプションを想定したレイアウトです。

使うもの: A6 横 ／ 名刺サイズ ＋ PDF

受賞作品の発表・告知

スプレッドシートの「賞など」に記入すると、キャプションにも反映されます。受賞作品だけを絞り込んで、SNS 用の正方形画像や配信画面用の画像を作れます。

使うもの: 正方形 ／ 16:9 横長 ＋ PNG

Web ページや配信画面への組み込み

HTML 出力は、余計な装飾のない、キャプションだけの単一ファイルです。文字がテキストとして残るので、コピーや読み上げができます。

使うもの: 任意のテンプレート ＋ HTML

イベントごとのデザイン

同梱のテンプレートを複製し、ブロックエディタでロゴやイベント名を足すだけで、そのイベント専用のキャプションになります。作ったテンプレートは、ファイルとして他の運営メンバーへ渡せます。

使うもの: ブロックエディタ ＋ テンプレートのインポート

X 以外で集めた作品にも

スプレッドシートへ直接入力した行や、フォームなどから集めた行も同じように出力できます。ブラウザ拡張は必須ではありません。

使うもの: スプレッドシート ＋ LABELSystem.exe

知っておいてほしいこと

使い始める前にご確認ください。

  • インターネット接続が必要です。データがスプレッドシートにあるためです。
  • URL とトークンは公開しないでください。スプレッドシートへ接続するための鍵です。漏れた可能性がある場合は、setup を再実行すると新しくなります。
  • フォントは同梱していません。同梱テンプレートは Noto Sans JP を使います。無い場合は代替フォントで描画し、警告を表示します。
  • ブラウザ拡張が読み取るのは、ページに表示されている内容だけです。Cookie やログイン情報には触れず、X API も使いません。
  • 応募者の情報の取り扱いにご注意ください。キャプションへの掲載は、コンテストの応募規約などで示した範囲で行ってください。
